MALTE'S LIFE — auf dem Windows-Laptop einrichten
================================================
Dauert etwa zwei Minuten. Es wird nichts "installiert",
nichts in Windows eingetragen und nichts verändert.
Die App ist ein Ordner, den man auch einfach wieder löschen kann.


SCHRITT 1 — Ordner anlegen
--------------------------
Kopieren Sie alle drei Dateien aus diesem Paket in einen Ordner
auf dem Laptop, zum Beispiel:

    C:\Malte

Die drei Dateien müssen zusammen in EINEM Ordner bleiben:
    MaltesLife.html
    Malte's Life starten.bat
    malteslife.ico


SCHRITT 2 — Einmal testen
-------------------------
Doppelklick auf   Malte's Life starten.bat

Kurz blitzt ein schwarzes Fenster auf, dann öffnet sich die App
in einem eigenen Fenster ohne Browser-Leiste.

Falls Windows warnt ("Der Computer wurde geschützt"):
    auf "Weitere Informationen" klicken
    dann auf "Trotzdem ausführen"
Das kommt, weil die Datei aus dem Internet stammt. Sie können
die Datei auch vorher freigeben:
    Rechtsklick auf die .bat  ->  Eigenschaften
    ->  ganz unten Haken bei "Zulassen"  ->  OK


SCHRITT 3 — Symbol auf den Desktop
----------------------------------
    Rechtsklick auf  Malte's Life starten.bat
    ->  Senden an  ->  Desktop (Verknüpfung erstellen)

Auf dem Desktop erscheint ein Symbol. Umbenennen in
"Malte's Life".


SCHRITT 4 — Schöneres Symbol (freiwillig)
-----------------------------------------
    Rechtsklick auf das neue Desktop-Symbol
    ->  Eigenschaften
    ->  oben auf den Reiter "Verknüpfung" wechseln
        (WICHTIG: auf "Allgemein" gibt es den Knopf nicht)
    ->  ganz unten Knopf "Anderes Symbol..."
    ->  Windows meldet jetzt: "... enthält keine Symbole"
        Das ist KEIN Fehler. Einfach auf OK klicken.
    ->  die Liste mit Windows-Symbolen ignorieren
    ->  "Durchsuchen..."
    ->  die Datei  malteslife.ico  aus Ihrem App-Ordner auswählen
    ->  Öffnen, dann OK, dann OK

Im selben Fenster können Sie unter "Ausführen" auch
"Minimiert" einstellen — dann blitzt das schwarze Fenster
nicht mehr auf.


SCHRITT 5 — An die Taskleiste (freiwillig)
------------------------------------------
    Rechtsklick auf das Desktop-Symbol
    ->  An Taskleiste anheften


FERTIG. Ein Klick, und die App startet.


WAS SIE NOCH WISSEN SOLLTEN
===========================

Vollbild
    Die App startet in einem eigenen Fenster im Hochformat, etwa so
    groß wie ein Handy. Das passt zum Aufbau der App.

    Wer lieber den ganzen Bildschirm möchte:
      - unten in der App auf "Vollbild" klicken, oder
      - die Taste F11 drücken
    Beides geht jederzeit wieder zurück. Die App merkt sich das
    nicht, sie startet immer wieder im Fenster.

    Das Fenster lässt sich auch ganz normal mit der Maus größer
    ziehen oder oben rechts maximieren.

Braucht die App Internet?
    Nein. Sie läuft komplett offline.

Die PIN
    Die PIN lautet 0902.

Wo wird der Fortschritt gespeichert?
    Auf dem Laptop, nicht im Internet. Der Browser legt ihn in einem
    Fach ab, dessen Name aus dem Speicherort der App gebildet wird.
    Liegt die App also woanders, sucht der Browser im falschen Fach
    und findet nichts — der Fortschritt sieht dann aus, als wäre er
    weg. (Er ist es nicht: Kommt die App zurück an ihren alten Platz,
    ist auch der Stand wieder da.)

    Deshalb: nach dem Einrichten den Ordner nicht mehr verschieben
    und nicht umbenennen. Falls es doch mal passiert, hilft die
    Sicherung.

Sicherung anlegen (empfohlen, dauert 20 Sekunden)
    In der App unten auf "FÜR ELTERN", PIN eingeben. Dort steht
    "Fortschritt sichern".

    1. Auf "Sicherung erzeugen" klicken.
       Der Text wird erzeugt, markiert und in die Zwischenablage
       gelegt.
    2. Mit Strg+V irgendwo einfügen und speichern. Es geht:
         - der Windows-Editor (Notepad)  ->  am einfachsten
         - Word                          ->  geht auch
         - eine E-Mail an sich selbst    ->  geht auch
       Speichern Sie sie zum Beispiel als  Sicherung  neben die App.

       Der Text ist lang (bei vollem Fortschritt rund 8000 Zeichen,
       also etwa zwei Seiten). Das ist normal — er wird kopiert,
       nicht abgetippt.

       Der Text besteht nur aus Großbuchstaben und den Ziffern 2 bis 7.
       Das ist Absicht: So kann die Autokorrektur von Word nichts
       daran verschlimmbessern.

    Wiederherstellen geht genauso rückwärts: Text kopieren, im
    selben Feld einfügen, auf "Sicherung einlesen" klicken.

    Das hilft nicht nur beim Verschieben, sondern auch wenn der
    Browser aufgeräumt wird oder die App auf einen anderen Rechner
    umziehen soll. Am besten einmal im Monat machen.

Das Vorlesen prüfen
    In der App unten auf "FÜR ELTERN", PIN eingeben, ganz unten
    auf "Vorlesen testen". Dort steht dann im Klartext, ob es
    funktioniert. Auf einem normalen Laptop sollte es gehen —
    auf Ihrem Arbeitszugang über den Server fehlt die Tonausgabe,
    deshalb ging es dort nicht.

Wenn etwas nicht geht
    Schicken Sie mir, was auf dem Bildschirm steht. Die App sagt
    inzwischen ziemlich genau, woran es hakt.
