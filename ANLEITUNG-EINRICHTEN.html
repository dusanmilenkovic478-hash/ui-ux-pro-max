Malte's Life einrichten

Alles, was Sie tun müssen — in acht Schritten. Es wird nichts in Windows eingetragen und nichts verändert. Die App ist ein Ordner, den man auch einfach wieder löschen kann.

⏱ Etwa 5 Minuten
1

Die ZIP-Datei herunterladen

Laden Sie MaltesLife-Windows.zip direkt auf Maltes Laptop herunter — nicht auf Ihren Arbeitsrechner und dann rüberkopieren. Das spart einen Umweg.

Wo sie landet, ist egal. Windows legt sie normalerweise im Ordner Downloads ab. Dort holen wir sie gleich wieder raus.

2

Einen Ordner für die App anlegen

Öffnen Sie den Explorer (das gelbe Ordnersymbol unten in der Leiste), klicken Sie links auf Dieser PC und doppelt auf Windows (C:).

Dann Rechtsklick auf eine freie Fläche:

Neu → Ordner

Nennen Sie ihn Malte. Fertig ist C:\Malte.

Ein anderer Ort geht auch. Nur nicht der Ordner „Downloads“ — da wird irgendwann aufgeräumt, und dann ist die App weg.

3

Die ZIP-Datei auspacken

  1. Rechtsklick auf MaltesLife-Windows.zip
  2. Alle extrahieren…
  3. Bei „Ziel“ eintragen: C:\Malte
  4. Auf Extrahieren klicken

Danach sieht es in C:\Malte so aus:

📁 C:\Malte ├ MaltesLife.html ← die App ├ Malte's Life starten.bat ← hier klicken ├ malteslife.ico ← das Symbol └ SO GEHT DIE INSTALLATION.txt
Wichtig

Diese Dateien müssen zusammen in einem Ordner bleiben. Einzeln funktionieren sie nicht.

4

Einmal ausprobieren

Doppelklick auf Malte's Life starten.bat

Kurz blitzt ein schwarzes Fenster auf — das gehört so. Dann öffnet sich die App in einem eigenen Fenster, ohne Adressleiste.

Falls Windows warnt

„Der Computer wurde durch Windows geschützt“ erscheint, weil die Datei aus dem Internet kommt. Sie ist in Ordnung:

Weitere Informationen → Trotzdem ausführen

Damit die Warnung nicht jedes Mal kommt: Rechtsklick auf die Datei → Eigenschaften → ganz unten Haken bei Zulassen → OK.

5

Symbol auf den Desktop legen

Rechtsklick auf Malte's Life starten.bat:

Senden an → Desktop (Verknüpfung erstellen)

Auf dem Desktop erscheint ein Symbol. Rechtsklick darauf → Umbenennen → Malte's Life.

Bei Windows 11 müssen Sie im Rechtsklick-Menü eventuell erst auf „Weitere Optionen anzeigen“ klicken.

6

Ein schöneres Symbol geben (freiwillig)

  1. Rechtsklick auf das neue Desktop-Symbol → Eigenschaften
  2. Wichtig: oben auf den Reiter Verknüpfung wechseln — auf „Allgemein“ gibt es den Knopf nicht
  3. Ganz unten: Anderes Symbol… → Durchsuchen…
  4. Die Datei malteslife.ico aus C:\Malte auswählen
  5. OK, dann nochmal OK
Viele Reiter — das ist normal

Weil die Verknüpfung auf eine Startdatei zeigt, blendet Windows zusätzlich Terminal, Schriftart, Layout und Farben ein. Die brauchen Sie alle nicht — nur Verknüpfung.

Auf demselben Reiter steht Ausführen: — dort auf Minimiert stellen, dann blitzt das schwarze Fenster beim Start nicht mehr auf.

7

Das Vorlesen prüfen

Das konnten wir bisher nicht testen, weil auf Ihrem Arbeitszugang die Tonausgabe fehlt. Auf Maltes Laptop sollte es gehen:

  1. In der App unten auf FÜR ELTERN
  2. PIN eingeben
  3. Ganz unten bei „Vorlesen auf diesem Gerät“ auf Vorlesen testen

Die App probiert dann sieben Einstellungen durch und sagt Ihnen im Klartext, welche funktioniert. Sie merkt sich das.

Hören Sie nichts, schicken Sie mir einfach den Text, der dort steht.

8

Eine Sicherung anlegen

Im selben Eltern-Bereich, etwas weiter oben:

  1. Auf Sicherung erzeugen klicken — der Text wird automatisch markiert und kopiert
  2. Word oder den Editor öffnen, mit Strg + V einfügen
  3. Speichern in C:\Malte, zum Beispiel als Sicherung

Der Text ist lang — bis zu zwei Seiten. Das ist normal.

Am besten einmal im Monat wiederholen

Damit ist der Fortschritt sicher, falls der Ordner verschoben wird, der Browser aufgeräumt wird oder der Laptop kaputtgeht.

0902

Die Eltern-PIN. Damit lösen Sie Gutscheine ein und öffnen den Eltern-Bereich. Bitte nicht im selben Ordner notieren, wo Malte sie findet.
